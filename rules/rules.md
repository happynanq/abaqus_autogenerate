========== СЛОВАРЬ ТЕРМИНОВ ==========
- «длина L, толщина t» для пластины/балки в 2D: L — размер по X,
  t — размер по Y (высота сечения). Толщина ИЗ плоскости не задана
  → 1 (в выбранных единицах) и явное допущение.
- «лежит на опорах» → отдельные детали + контакт, а не заделка пластины.
- «консольно-закреплённые опоры» → опоры закреплены только основанием,
  верх свободный (контактирует с пластиной).
- «нулевые перемещения и повороты» → u1=u2=ur3=0 (Encastre в 2D).
- «Tangential behavior, Rough» → TangentialBehavior(formulation=ROUGH);
  нормальное поведение по умолчанию Hard contact, allowSeparation=ON.
- «Статический, линейные возмущения» → StaticLinearPerturbationStep.
  Требует базового шага: Static General (BaseStep), затем
  linear perturbation. Нагрузка задаётся в ПЕРТУРБАЦИОННОМ шаге.
  Контакт должен быть замкнут в базовом состоянии (нулевой зазор при
  сборке, детали касаются точно: координаты стыка совпадают).
  Если базовое состояние даёт rigid body motion — допустимо добавить в
  базовый шаг минимальную нагрузку/смещение и ЯВНО написать об этом.
  Не подменяй тип анализа на другой молча.
- «Концентрированная сила в точке» → ConcentratedForce на вершине
  (vertex), созданной разбиением/эскизом. Точка нагрузки должна быть
  вершиной геометрии до построения сетки.
- «CPS4R» → plane stress, reduced integration; elemLibrary=STANDARD.
- «Деформируемая 2D поверхность» → TWO_D_PLANAR, DEFORMABLE_BODY, BaseShell.
- «Опора квадратная со скруглёнными углами радиуса R» → если не указано
  иное, скруглены ВСЕ четыре угла. Сделай параметр
  ROUND_CORNERS = ('TL','TR','BL','BR') в CONFIG и пометь допущение.

========== ПРАВИЛА КОДА ==========
1. Python 2.7: без f-строк, `print` как оператор/с одним аргументом,
   `open(f,'wb')` для csv, словари без dict comprehension-новинок.
   Первая строка: `# -*- coding: mbcs -*-`.
2. Импорты: `from abaqus import *`, `from abaqusConstants import *`,
   `from caeModules import *`, `import regionToolset, os, traceback`.
3. Все размеры, трактовки и имена — в блоке CONFIG вверху. Никаких
   «магических чисел» в теле кода.
4. Геометрию выбирай через `getByBoundingBox` или `findAt`
   с допуском; НИКОГДА по индексам (`edges[3]`).
5. Контактные поверхности: `side1Edges`/`side2Edges` зависят от нормали.
   После создания проверь, что нормали направлены друг на друга;
   при ошибке меняй сторону. Master — более жёсткая/крупная поверхность.
6. Граничные условия на закрепление ставь в 'Initial'.
   Нагрузки — в нужном шаге (для perturbation — в нём).
7. Сетка:
   - Для CPS4R (reduced integration) по высоте изгибаемой детали
     минимум 4 элемента (иначе hourglass и завышенные прогибы).
   - ЛИМИТ Student Edition: 1000 узлов на ВСЮ модель (сумма по деталям
     и экземплярам). До расчёта посчитай оценку:
     узлов ≈ (nx+1)*(ny+1) на каждую деталь × число экземпляров.
     Если >1000 — укрупни сетку вдоль длинной стороны, сохранив
     ≥4 элемента по высоте. Желательно оставить запас ≥10%.
   - После meshing выведи фактическое число узлов
     (`len(a.instances[..].nodes)` по всем экземплярам) и прерви скрипт,
     если >1000.
   - Сетку задавай на детали (`seedEdgeBySize`/`seedPart`),
     затем `a.regenerate()`.
8. Выходные величины: `fieldOutputRequests` минимум ('S','U','RF').
   Не запрашивай CSTATUS/CPRESS, если они не нужны (ломает 2018).
9. Задание и расчёт: `mdb.Job`, `job.submit(consistencyChecking=OFF)`,
   `job.waitForCompletion()`, затем проверь `job.status == COMPLETED`.
   При неудаче прочитай хвост .msg и вызови ошибку с понятным текстом.
10. Оборачивай main() в try/except с `traceback.print_exc()` и
    повторным raise. Никаких тихих `except: pass`.
11. Имена объектов в ODB — в ВЕРХНЕМ регистре (`PLATE-1`, множества тоже).
12. Перед расчётом сохрани картинку геометрии (см. «Визуальная проверка»).

========== ГРАФИКИ: ТОЛЬКО ВНУТРИ ABAQUS ==========
ЗАПРЕЩЕНО: matplotlib, numpy, pandas, любые внешние библиотеки,
построение графиков вне Abaqus. Разрешено: модуль visualization,
session.Path, XYDataFromPath, XYPlot, session.printToFile,
session.writeXYReport (для выгрузки чисел из тех же XYData).

Шаблон графика вдоль ребра:
  odb = session.openOdb(name=ODB_PATH, readOnly=True)
  vp = session.viewports['Viewport: 1']
  vp.setValues(displayedObject=odb)
  vp.odbDisplay.setFrame(step=STEP_INDEX, frame=-1)   # последний кадр

  # ограничь отображение пластиной, чтобы не цеплять опоры
  leaf = dgo.Leaf(...)  /  session.Leaf + session.DisplayGroup ...
  (или смещай точки пути внутрь на EPS=1e-3*размер, чтобы не попасть
   на узлы соседней детали)

  vp.odbDisplay.setPrimaryVariable(variableLabel='S',
      outputPosition=INTEGRATION_POINT, refinement=(COMPONENT,'S11'))
  pth = session.Path(name='P_bottom', type=POINT_LIST,
      expression=((x0,y,0.0),(x1,y,0.0)))
  # точек пути достаточно много или path вдоль узлов ребра
  xy = session.XYDataFromPath(path=pth, name='S11_bottom',
      includeIntersections=True, shape=UNDEFORMED,
      labelType=X_COORDINATE, pathStyle=PATH_POINTS, numIntervals=N)

  plot = session.XYPlot('Plot_S11')
  chart = plot.charts.values()[0]
  curve = session.Curve(xyData=xy)
  chart.setValues(curvesToPlot=(curve,))
  chart.axes1[0].axisData.setValues(useSystemTitle=False, title='x, mm')
  chart.axes2[0].axisData.setValues(useSystemTitle=False, title='S11, MPa')
  vp.setValues(displayedObject=plot)
  session.printToFile(fileName='S11_bottom', format=PNG,
      canvasObjects=(vp,))
  session.writeXYReport(fileName='S11_bottom.rpt', xyData=(xy,))

Для перемещений аналогично: setPrimaryVariable('U', NODAL, (COMPONENT,'U2')).
Для каждого заданного графика: заголовок, подписи осей с единицами,
сетка, один PNG и один .rpt. Если задан участок («нижняя сторона
пластины») — точки пути строго вдоль него.

========== ПРОВЕРКА РЕЗУЛЬТАТА ==========
В конце скрипта (внутри Abaqus Python) выведи в консоль и в файл
summary.txt:
 - число узлов и элементов, статус задания;
 - максимальные |U2| и |S11| по пластине;
 - аналитическую оценку для балки на двух опорах
   (δ = P·L³/(48·E·I), I = b·h³/12, L — пролёт между опорами),
   отношение численного к аналитическому значению;
 - предупреждение, если отклонение >20 % (ищи причину: единицы,
   положение опор, контакт, нелинейность, толщина из плоскости).
Ничего не «подгоняй» под аналитику: отклонение просто сообщай.
